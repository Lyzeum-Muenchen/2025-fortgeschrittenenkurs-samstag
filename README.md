### Hot-Swap Funktionalität
1. Installation des Vaadin Plugin in IntelliJ (Plugins -> Marketplace -> Suche nach "Vaadin")
2. Erstellung einer neuen Applikation-Configuration:
    - "Drei Punkte" (rechts neben "Play Button") -> Edit -> Add new Application -> JDK und Main-Klasse "Application" auswählen
3. Start über "Drei Punkte" (rechts neben "Play Button") und Auswahl "Restart Debug using HotswapAgent"
    - Nach jedem Save (STRG + S) wird der neue Inhalt automatisch übertragen
    - Hinweis: HotSwap funktioniert nicht bei neu angelegten Dateien.
